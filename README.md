# Agentic Workflows: labs

One folder per session in `sessions/<session>/lab-session/`, each with its own `README.md`.

```bash
uv sync                     # one environment for the whole course
cp .env.example .env        # add your API key from Session 3 on (never commit it)
git pull                    # before each session: new labs appear here
```

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/).
